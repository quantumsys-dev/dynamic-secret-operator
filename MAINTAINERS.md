# Project Maintainers

This document defines the maintainers of the **Dynamic Secret Operator (DSO)** project, following CNCF governance standards.

Maintainers are responsible for code reviews, architecture decisions, release management, and upholding project security and community health.

## Governance & Responsibilities

1. **Pull Request Reviews**: All code contributions require at least one approval from a project maintainer before merge.
2. **Release Management**: Official image builds, Helm chart publications, SLSA provenance generation, and Cosign OIDC signings are restricted to Lead Maintainers.
3. **Security Vulnerability Handling**: Security disclosures sent to `security@quantumsys.dev` are triaged within 48 hours according to our [Security Policy](SECURITY.md).
4. **Code of Conduct Enforcement**: Escalations regarding community behavior are resolved in accordance with [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

---

## Becoming a Maintainer

Contributors who demonstrate sustained technical leadership, active review participation, and alignment with CNCF standards may be nominated for maintainership by an existing maintainer. Maintainer status is confirmed by unanimous agreement of the active maintainers team.
