# Security Policy

## Supported Versions

We release patches and security fixes for the active versions of `dynamic-secret-operator`.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The QuantumSys security and architecture team takes security vulnerabilities seriously.

If you discover a security vulnerability in `dynamic-secret-operator`, please **DO NOT** create a public GitHub issue.

Instead, please report the vulnerability privately via GitHub Security Advisories or by emailing:
`security@quantumsys.io`

### Information to Include
- Detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact and affected versions.
- Any suggested mitigations.

### Response SLA
- **Initial Acknowledgement:** Within 24 hours.
- **Triage & Severity Assessment:** Within 48 hours.
- **Patch & Public Disclosure:** Coordinated disclosure timeline (standard 90 days or faster for critical issues).
